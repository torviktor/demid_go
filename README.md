## Как работает

- Прогресс сохраняется в браузере (localStorage)
- Кнопка «Отчёт папе» — генерирует текстовый отчёт о прогрессе для отправки в мессенджер
- На каждом устройстве свой прогресс (синхронизации между устройствами нет)

## Если страница не открывается

Включи GitHub Pages в Settings → Pages:
- Source: Deploy from a branch
- Branch: main, папка: / (root)
- Сохрани и подожди 1-2 минуты до первого деплоя
